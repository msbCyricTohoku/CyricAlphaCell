CyricAlphaCell (C.A.C) v1.0.0 — User Manual & Physics Reference

Getting Started in 4 Steps

  1. Configure Physics & Medium: Open the Physics and Source tabs to set particle histories (nps_total), alpha energy (src_E0), and ICRU tissue parameters (.dedx, rho_mat, Z_eff, A_eff).
  2. Set MKM Radiobiology: In Bio (MKM), set the micro-domain diameter d (typically 0.5 µm for alpha particles) and reference X-ray alpha_X, beta_X values.
  3. Design Your 3D Cellular Colony: Use the Colony tab to generate 2D/3D lattices (Hex, Square, Ring, Line, 3D HCP Spheroid, 3D Cubic) or load one of the three built-in benchmark cases. Drag cells across XY, XZ, or YZ planes and inspect in 3D Orbit view.
  4. Export & Run C.A.C: Click Export .i File to download inputs.i, then run:
$ ./cac.bin inputs.i

Strict 3D Non-Overlap Rule

C.A.C requires strictly disjoint cytoplasmic spheres in 3D space. This configurator enforces a minimum center-to-center distance of 1.001 × (R_cyto,i + R_cyto,j) during dragging, editing, generation, and file import. When dragging into another cell, your cell slides cleanly along the boundary without penetrating it.

Particle Transport & Bohr Straggling

CyricAlphaCell transports alpha particles via the Continuous-Slowing-Down Approximation (CSDA) interpolated from NIST ASTAR stopping power tables, coupled with randomized energy-loss straggling sampled from a bounded Lognormal-Gaussian distribution:

sigma_Bohr^2 = 4 * pi * z^2 * Z_eff * e^4 * N * ds

Microdosimetry

Specific energy z, frequency-mean specific energy z_F, and dose-averaged LET L_D are scored across target domains:

z = epsilon / m z_F = (Sum of z_i) / N_hits L_D = (Sum of L_i * epsilon_i) / (Sum of epsilon_i)

Microdosimetric Kinetic Model (MKM) & Overkill Saturation

For a domain of diameter d (µm), the analytic dose-mean specific energy z_D is corrected for high-LET overkill using saturation parameter z_0 (from y_0 = 150 keV/µm):

z_D = (0.204 * L_D) / d^2 z_D* = (z_0^2 / z_D) * (1 - exp(-(z_D^2) / z_0^2)) alpha = alpha_X + beta_X * z_D* S = exp(-alpha * D - beta_X * D^2)

Input File Structure (.i)

C.A.C reads a strict whitespace-separated file ignoring # comments. All spatial coordinates and radii are in centimeters (cm), while d is in µm and energies are in MeV.

  • Block 1 (6 lines): nps_total, global_ds, e_cut, use_straggling, max_tracks, output_dir
  • Block 2 (7 lines): src_mode, src_E0, src_x src_y src_z, dedx_file, rho_mat, Z_eff, A_eff
  • Block 3 (4 lines): d, ref_dose, alpha_X, beta_X
  • Block 4 (2 lines): save_svg, render_window
  • Block 5 (1 + N lines): num_cells followed by ID X Y Z R_nuc R_cyto Source_Probability

Generated Output Files

  • cellular_dosimetry.dat — Macroscopic dose & hit counts per nucleus and cytoplasm.
  • radiobiology_rbe.dat — z_F, z_D, L_D, Survival Fraction, and RBE per cell.
  • microdosimetry_z_spectra.dat — Analytic f1(z) distribution for the MKM domain.
  • let_spectra.dat — Dose-averaged LET spectrum.
  • tracks.dat — 3D XYZ track coordinate projections.
  • *.svg — Native vector plots (when save SVG = 1).

Viewport Interactions

  • Click Cell: Select cell and open its parameters in the right Inspector.
  • Drag Cell (XY / XZ / YZ views): Reposition cell within the active plane with real-time 3D overlap rejection.
  • Drag Golden Star (src_mode = 1): Reposition the 3D point source directly in any 2D view.
  • Drag Empty Space: Pan camera in 2D views, or Orbit camera in 3D view.
  • Mouse Wheel: Zoom smoothly toward cursor (2D) or center (3D).
  • Drag & Drop a .i File: Drop any C.A.C input file directly onto the canvas to load and inspect it.

Keyboard Shortcuts

  • Ctrl + Z — Undo geometry change
  • Ctrl + Y — Redo geometry change
  • Delete / Backspace — Delete selected cell
  • F — Fit all cells into viewport
  • 1 2 3 4 — Switch between XY, XZ, YZ, and 3D views
